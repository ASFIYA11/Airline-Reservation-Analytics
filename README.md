# Airline Reservation & Analytics System

## Project Overview

The Airline Reservation & Analytics System is a relational database project developed using MySQL. The system manages airline operations including flight scheduling, passenger information, booking management, crew assignments, and business analytics.

The project demonstrates practical implementation of SQL concepts such as joins, aggregate functions, grouping, subqueries, window functions, and stored procedures.

---

# Objectives

* Manage flight information efficiently.
* Store passenger details.
* Record and track flight bookings.
* Maintain crew assignment information.
* Generate analytical reports for airline operations.
* Demonstrate SQL database design and querying techniques.

## 📊 Sample Analytics Queries

### Revenue by Flight

```sql
SELECT
    f.flight_number,
    SUM(b.fare_paid) AS revenue
FROM Flights f
JOIN Bookings b
ON f.flight_id = b.flight_id
GROUP BY f.flight_number
ORDER BY revenue DESC;
```

### Flight Revenue Ranking

```sql
SELECT
    f.flight_number,
    SUM(b.fare_paid) AS revenue,
    RANK() OVER(
        ORDER BY SUM(b.fare_paid) DESC
    ) AS revenue_rank
FROM Flights f
JOIN Bookings b
ON f.flight_id = b.flight_id
GROUP BY f.flight_number;
```

### Dense Ranking

```sql
SELECT
    f.flight_number,
    SUM(b.fare_paid) AS revenue,
    DENSE_RANK() OVER(
        ORDER BY SUM(b.fare_paid) DESC
    ) AS revenue_rank
FROM Flights f
JOIN Bookings b
ON f.flight_id = b.flight_id
GROUP BY f.flight_number;
```
