# Airline Reservation & Analytics System

## Project Overview

The Airline Reservation & Analytics System is a relational database project developed using MySQL. The system manages airline operations including flight scheduling, passenger information, booking management, crew assignments, and business analytics.

The project demonstrates practical implementation of SQL concepts such as joins, aggregate functions, grouping, subqueries, window functions, and stored procedures.

---

# Objectives

* Manage flight information efficiently.
* Store passenger details.
* Record and track flight bookings.
* Maintain crew assignment information.
* Generate analytical reports for airline operations.
* Demonstrate SQL database design and querying techniques.

---

# Database Design

## Tables Used

### Flights

Stores flight schedules and ticket information.

### Passengers

Stores passenger details.

### Bookings

Stores booking transactions.

### Crew

Stores airline crew information.

### Crew_Assignments

Maps crew members to flights.

---

# Relationships

* One Flight can have many Bookings.
* One Passenger can have many Bookings.
* One Flight can have multiple Crew Members.
* One Crew Member can work on multiple Flights.

# Sample Analytical Queries

## Flight Occupancy Analysis

Displays the number of booked seats per flight.

## Revenue Analysis

Calculates revenue generated by each flight.

## Passenger Booking Analysis

Shows passenger details along with flight and seat information.

## Flight Ranking

Ranks flights according to revenue generated using RANK() and DENSE_RANK().

## Fare Analysis

Identifies flights with the highest ticket prices and bookings above average fare.

---

# Stored Procedure

### GetFlightBookings

Returns the number of bookings for a given flight.

Example:

```sql
CALL GetFlightBookings(1);
```
